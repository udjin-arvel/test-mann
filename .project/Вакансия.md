Мы развиваем действующую SaaS-платформу на базе AI-агентов, которые автоматизируют коммуникации с клиентами, работу с CRM, мессенджерами и бизнес-процессами.

Ищем не просто разработчика, который знает Python и React. Нам нужен инженер, который уже самостоятельно создавал полноценный программный продукт - от архитектуры до запуска в production.

Особенно интересен опыт:

Запуска собственного IT-продукта или стартапа.

Работы техническим сооснователем (Technical Co-founder).

Самостоятельной разработки SaaS, CRM, веб-платформы или другого сложного сервиса.

Ответственности за весь продукт в небольшой команде, где нет отдельного специалиста на каждую техническую задачу.

Нам важен не статус основателя, а подтверждённый опыт самостоятельного создания работающего продукта.


Чем предстоит заниматься:

Развивать существующую AI SaaS-платформу: создавать функциональность, исправлять ошибки, улучшать архитектуру.

Самостоятельно разрабатывать Backend и Frontend.

Создавать и развивать AI-агентов, интеграции с CRM, мессенджерами и внешними API.

Проектировать базы данных, фоновые процессы и асинхронные задачи.

Отвечать за полный цикл разработки: задача → архитектура → код → тестирование → production.

Использовать AI-инструменты для ускорения разработки, самостоятельно проверяя качество и корректность кода.

Что для нас принципиально важно:

1. Опыт самостоятельного создания продукта

Вы лично проектировали и разрабатывали полноценный веб-сервис, SaaS, стартап или существенную часть продукта с ответственностью за Backend, Frontend и запуск.

Важно, чтобы вы могли показать результат, объяснить архитектуру и рассказать, какие решения принимали самостоятельно.

2. Опыт разработки AI-функциональности

Интересен практический опыт интеграции LLM API, создания AI-агентов, tool calling, RAG, работы с контекстом и памятью диалогов.

Важно: использование ChatGPT, Cursor или Claude Code для написания кода само по себе не считается опытом разработки AI-продуктов.

Кому вакансия, скорее всего, не подойдёт

Разработчикам, которые занимались исключительно Frontend или исключительно Backend.

Специалистам, чей опыт ограничен отдельными задачами в большой команде без ответственности за интеграцию и запуск.

Разработчикам, использовавшим AI только как помощника для написания кода.

Кандидатам без опыта работы с production-системами.
